Regiões Postais e Estrutura de CEPs no Brasil

O Código de Endereçamento Postal (CEP) brasileiro possui 8 algarismos estruturados geograficamente. O primeiro dígito identifica a região postal (ex: 0 e 1 para SP, 2 para RJ/ES, 3 para MG, 4 para BA/SE, etc.). O Caixa do Dev valida as faixas oficiais de todos os 27 estados.
