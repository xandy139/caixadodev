Boas Práticas de Códigos de Status HTTP em APIs REST

O protocolo HTTP define códigos de resposta padronizados divididos em 5 classes: 1xx (Informativos), 2xx (Sucesso), 3xx (Redirecionamento), 4xx (Erro do Cliente) e 5xx (Erro do Servidor).

Construir APIs de alto padrão exige semântica correta: utilize 201 Created ao criar novos recursos via POST, 204 No Content após exclusões bem-sucedidas via DELETE, 400 Bad Request ou 422 Unprocessable Entity para dados de entrada inválidos e 404 Not Found quando a entidade não existir.
