O Padrão Markdown e a Especificação GitHub Flavored Markdown (GFM)

Criado em 2004 por John Gruber em colaboração com Aaron Swartz, o Markdown tornou-se o padrão incontestável para redação técnica, documentação de repositórios (arquivos README), escrita de blogs para programadores e anotações técnicas. Seu princípio fundamental é simples: permitir que qualquer pessoa escreva texto estruturado utilizando formatação de texto puro legível tanto por humanos quanto por compiladores HTML.

Perguntas Frequentes sobre Markdown (FAQ)

O que é CommonMark?+
CommonMark é uma especificação padrão rigorosa e não ambígua criada pela comunidade de desenvolvimento em 2014 para resolver inconsistências e divergências de interpretação de sintaxe que existiam entre os dezenas de compiladores diferentes de Markdown no mercado.
Como inserir quebras de linha simples no Markdown?+
Na especificação padrão, uma quebra de linha comum no editor de texto é ignorada. Para forçar uma quebra de linha (<br>) sem iniciar um novo parágrafo, insira dois espaços em branco no final da linha antes de pressionar Enter.
O editor armazena meus textos em servidores?+
Não! Todo o parsing e renderização de Markdown para HTML acontecem localmente na memória do seu navegador web. Seus artigos, anotações e documentos confidenciais nunca são enviados a servidores externos.
