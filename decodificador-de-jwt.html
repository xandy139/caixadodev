Entenda a Arquitetura de Tokens JWT (RFC 7519)

O JSON Web Token (JWT) é o padrão industrial estabelecido pela RFC 7519 da IETF para transmissão compacta e independente de declarações de segurança (claims) entre duas partes. Em arquiteturas contemporâneas de APIs REST, microsserviços e OAuth 2.0 / OpenID Connect, o JWT é a principal credencial de autenticação e autorização sem estado (stateless).

1. Estrutura dos 3 Componentes

Um JWT é formado por três partes codificadas em Base64Url unidas por pontos (Header.Payload.Signature):

  • Header: Contém o tipo do token (typ: "JWT") e o algoritmo criptográfico de assinatura (ex: alg: "HS256" ou alg: "RS256").
  • Payload: Contém as declarações (claims) de identidade do usuário e contexto da sessão. O payload não é criptografado por padrão; ele é apenas codificado. Portanto, nunca armazene segredos de estado ou senhas no payload.
  • Signature: O hash criptográfico gerado com a chave privada ou chave secreta compartilhada do servidor, garantindo que o token não foi adulterado durante o transporte.

2. Claims Padronizadas Mais Relevantes

Claim Nome Completo Descrição Técnica
sub Subject (Assunto) Identificador único do usuário no banco de dados (ex: UUID ou ID numérico).
exp Expiration Time Timestamp UNIX em segundos a partir do qual o token perde a validade.
iat Issued At Timestamp UNIX exato em que o token foi emitido pelo servidor de autenticação.
iss Issuer (Emissor) Identificador do serviço que emitiu o token (ex: 'https://auth.caixadodev.com.br').

Perguntas Frequentes sobre JWT (FAQ)

O decodificador da Caixa do Dev valida a assinatura criptográfica?+
O decodificador inspeciona visualmente os dados contidos no Header e no Payload e converte os timestamps UNIX de expiração para datas legíveis em horário local. A validação criptográfica da assinatura depende da chave secreta privada, que só existe no servidor da sua aplicação.
É seguro colar tokens de autenticação corporativos nesta ferramenta?+
Sim! Todo o processamento é 100% Client-Side. O código de decodificação roda exclusivamente na engine JavaScript do seu próprio navegador, sem enviar nenhuma requisição de rede para nossos servidores.
