Guia de Funções Hash Criptográficas: MD5, SHA-1, SHA-256 e SHA-512

Uma Função Hash Criptográfica é um algoritmo matemático determinístico que mapeia dados de tamanho arbitrário (uma palavra, um parágrafo ou um arquivo de vários gigabytes) para uma saída de tamanho fixo em formato hexadecimal (chamada de digest ou hash). Propriedades fundamentais definem um hash seguro: é uma função de sentido único (unidirecional / one-way) e resistente a colisões (onde duas entradas diferentes nunca devem produzir a mesma saída).

1. Comparativo de Algoritmos Hash Populares

Algoritmo Tamanho do Digest Status de Segurança Aplicação Recomendada
MD5 128 bits (32 hex) Inseguro (Vulnerável) Apenas para somas de verificação rápida contra corrupção acidental.
SHA-1 160 bits (40 hex) Depreciado (Colisões provadas) Legado histórico (Git internals v1, compatibilidade antiga).
SHA-256 256 bits (64 hex) Seguro (Padrão ouro) Assinaturas digitais, certificados TLS/SSL, blockchain e integridade.
SHA-512 512 bits (128 hex) Altíssima Segurança Aplicações de defesa, criptografia militar e sistemas financeiros.

2. Por que SHA-256 Não Deve Ser Usado para Senhas Sem Salt

Embora o SHA-256 seja matematicamente seguro contra colisões, ele foi projetado por engenharia para ser extremamente rápido. Por isso, placas de vídeo (GPUs) modernas conseguem calcular bilhões de hashes SHA-256 por segundo em ataques com tabelas Rainbow. Para salvar senhas de usuários em bancos de dados, utilize algoritmos deliberadamente lentos com fator de custo e salt automático, como bcrypt, Argon2id ou PBKDF2.

Perguntas Frequentes sobre Hashes (FAQ)

É possível reverter um hash para descobrir o texto original?+
Matematicamente não, pois o hash descarta informações durante a compressão de bits. No entanto, se o texto original for uma senha comum (como '123456'), invasores podem consultar bancos de dados pré-computados (Rainbow Tables) onde o hash já foi associado à palavra original.
A ferramenta utiliza bibliotecas externas ou a API nativa do navegador?+
Para a família SHA (SHA-1, SHA-256, SHA-512), a ferramenta utiliza a Web Crypto API nativa do navegador (crypto.subtle.digest()), garantindo velocidade de hardware e segurança local sem tráfego de rede.
