# 📦 Caixa do Dev (`caixadodev.com.br`)

> O maior canivete suíço de ferramentas online gratuitas para desenvolvedores, analistas de QA, engenheiros de DevOps e profissionais de tecnologia do Brasil.
> Inspirado nas melhores funcionalidades do **4Devs** e suítes modernas como **DevToys** e **CyberChef**, mas com visual Dark Mode refinado (Linear / VS Code), carregamento instantâneo e **100% Client-Side** (zero envio de dados a servidores).

---

## ✨ Catálogo Completo das 40 Ferramentas

### 👤 1. Massa de Testes & Documentos Oficiais (4Devs Modernizado)
1. **Gerador de Pessoas (Dados Fictícios Completos)**: Cadastros brasileiros completos (Nome, CPF, RG, Idade, Data de Nascimento, Sexo, Tipo Sanguíneo, E-mail, Celular, CEP, Endereço, Bairro, Cidade e Estado).
2. **Gerador de Empresa (PJ Completa)**: Razão Social, Nome Fantasia, CNPJ, Inscrição Estadual (IE), CNAE e Capital Social.
3. **Gerador em Lote de Mock Data**: Gera 5 a 100 registros estruturados customizados para bancos de dados com exportação para JSON, CSV e comandos SQL `INSERT INTO`.
4. **Gerador e Validador de CPF / CNPJ**: Algoritmo matemático oficial Módulo 11 com máscara e detecção de Região Fiscal.
5. **Gerador e Validador de RG (Registro Geral)**: Identidade civil no padrão SSP-SP com cálculo de dígito verificador numérico ou X.
6. **Gerador de Certidão CNJ (Nascimento, Casamento, Óbito)**: Provimento nº 63/2017 do CNJ com 32 dígitos e cálculo dos 2 DVs (Módulo 11).
7. **Gerador e Validador de CNH**: Carteira Nacional de Habilitação com cálculo oficial dos 2 dígitos verificadores do Renach.
8. **Gerador e Validador de PIS / PASEP**: 11 dígitos com cálculo Módulo 11 para folhas de pagamento e DP.
9. **Gerador e Validador de Título de Eleitor**: 12 dígitos com código de Unidade Federativa (UF) e dígitos verificadores do TSE.
10. **Gerador e Validador de Cartão de Crédito**: Algoritmo de Luhn (Módulo 10), chip interativo, CVV e detecção de bandeira (Visa, Mastercard, Amex, Elo, Hipercard).
11. **Gerador de Contas Bancárias**: Agência e conta corrente com dígitos verificadores para BB, Bradesco, Caixa, Itaú, Santander, Nubank e Banco Inter.
12. **Gerador de Placas de Veículo & RENAVAM**: Placa Mercosul (`BRA2E19`), tradicional (`ABC-1234`) e código RENAVAM oficial com Módulo 11.
13. **Gerador e Consulta de CEP**: Geração por faixas oficiais dos Correios para os 27 estados e consulta em tempo real via ViaCEP com fallback offline seguro.

### 💻 2. Código, Frontend & TypeScript
14. **Conversor JSON para TypeScript**: Transforma payloads JSON em interfaces e types tipados do TypeScript em tempo real.
15. **Conversor de cURL**: Converte comandos cURL para JavaScript `fetch()`, `axios`, Python `requests` e PHP `cURL`.
16. **Editor e Visualizador de Markdown**: Renderização em tempo real de Markdown para HTML com suporte a tabelas GFM, blocos de código e tarefas.
17. **Formatador e Minificador de HTML & CSS**: Indentação inteligente ou compressão em linha única para acelerar o Core Web Vitals.
18. **Testador de Regex (Expressões Regulares)**: Validador com highlight visual de correspondências e presets (email, CPF, URL).
19. **Formatador e Minificador de SQL**: Embeleza queries complexas (SELECT, JOINs, subqueries) e opção de maiúsculas.
20. **Comparador de Arquivos e Textos (Diff)**: Comparação linha a linha em tempo real com destaque visual de adições (+) e remoções (-).
21. **Formatador e Validador de JSON**: Indentação com 2 ou 4 espaços, minificação e localizador de erros de sintaxe.
22. **Conversor JSON <> CSV**: Conversão bidirecional entre arrays JSON e tabelas CSV para Excel.

### 🔒 3. Criptografia & Segurança
23. **Gerador de Hashes**: Cálculo instantâneo via Web Crypto API de MD5, SHA-1, SHA-256 e SHA-512.
24. **Decodificador de JWT (JSON Web Token)**: Inspeção local de Header e Payload com validação de expiração no Horário de Brasília.
25. **Gerador de Senhas Seguras & Entropia**: Senhas aleatórias de 8 a 64 caracteres com medidor de força e cálculo de bits de entropia.
26. **Gerador de UUID / GUID v4**: Identificadores criptograficamente seguros em lote (1 a 100) ou unitário, com ou sem hífens.

### 🎨 4. Design & CSS Moderno
27. **Gerador de Box-Shadow & Glassmorphism**: Sliders visuais para desfoque, espalhamento, cor, opacidade e efeito vidro fosco com CSS gerado.
28. **Otimizador de SVG & Data URI para CSS**: Minifica vetores SVG e converte para `background-image: url("data:image/svg+xml...")` e Base64.
29. **Conversor de Cores (HEX, RGB, HSL)**: Seletor visual, conversão instantânea de formatos e análise de contraste WCAG.

### 💼 5. Carreira Dev BR & Calculadoras
30. **Calculadora Comparativa CLT vs PJ**: Comparativo financeiro realista para programadores com tabela progressiva do INSS, IRPF, FGTS, 13º, férias vs Simples Nacional (Anexo III Fator R 28%), Pró-labore e líquido real anual.
31. **Conversor de Armazenamento & Tempo de Download**: Conversão entre bytes decimais (KB, MB, GB) e binários (KiB, MiB, GiB), e estimativa de tempo de transferência por Mbps/Gbps.

### 🌐 6. Redes, DevOps & Utilitários Web
32. **Gerador e Tradutor de Cron Expression**: Tradução de expressões cron para português claro, agendamentos comuns e previsão das próximas 5 execuções.
33. **Inspetor e Construtor de URL / Query Params**: Decompõe URLs e permite gerenciar parâmetros de busca (?chave=valor) com tabela interativa.
34. **Calculadora de Sub-rede IP / CIDR**: Cálculo de máscara de rede, IP de broadcast, faixa útil de hosts e total de endereços.
35. **Catálogo de Códigos de Status HTTP**: Guia de referência interativo para códigos HTTP (200, 201, 400, 401, 404, 500) em APIs REST.
36. **Conversor de Formato de Texto (Case Converter)**: Conversão instantânea entre `camelCase`, `PascalCase`, `snake_case`, `kebab-case`, `CONSTANT_CASE` e `Title Case`.
37. **Conversor de Timestamp Unix (Epoch)**: Relógio ao vivo com milissegundos, conversão de Epoch para data e vice-versa.
38. **Codificador & Decodificador Base64 e URL**: Suporte total a UTF-8 (sem quebra de acentos em português).
39. **Gerador de QR Code**: Geração de imagens em alta definição a partir de links, textos ou Pix com download em PNG.
40. **Gerador de Lorem Ipsum & Contador de Texto**: Texto de preenchimento e estatísticas em tempo real (caracteres, palavras, linhas e tempo de leitura).

## 🔍 Busca Rápida Global (`Ctrl + K`)
Atalho universal ou clique na barra de busca para filtrar instantaneamente entre as 40 ferramentas com navegação rápida por teclado.

---

## 🔒 Vantagem Competitiva: 100% Client-Side e Privacidade Total
Enquanto outros sites enviam requisições a servidores remotos e demoram para responder:
- Na **Caixa do Dev**, **todo o processamento roda localmente no navegador**.
- Nenhum CPF, dado de cliente, token de autenticação ou query SQL é transmitido para a internet.
- Carregamento instantâneo (**sub-100ms**).
- Custo de hospedagem: **R$ 0,00** (compatível com hospedagem estática Vercel, Cloudflare Pages ou GitHub Pages).

## 🚀 Como Publicar no Ar
1. Suba este projeto para um repositório no seu GitHub.
2. Conecte ao [Vercel](https://vercel.com) ou [Cloudflare Pages].
3. O arquivo `vercel.json` já contém os cabeçalhos de segurança (X-Frame-Options, X-Content-Type-Options) e regras de cache.
4. Aponte o domínio `caixadodev.com.br` para o servidor.
