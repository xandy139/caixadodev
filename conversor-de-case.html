Convenções de Nomenclatura em Linguagens de Programação

Cada linguagem de programação e ecossistema adota convenções de nomenclatura consagradas para facilitar a legibilidade do código em equipe: camelCase em JavaScript/TypeScript, PascalCase para classes e tipos, snake_case em Python e bancos de dados SQL, e kebab-case em seletores CSS e URLs.

Esta ferramenta acelera refatorações de código, permitindo converter instantaneamente nomes de colunas, variáveis e identificadores para o padrão adotado no seu projeto.
